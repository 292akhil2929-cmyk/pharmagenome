# Research association snapshot

Captured from the official Open Targets GraphQL API and Ensembl REST on 2026-09-08. Raw bytes and per-request queries, variables, URLs, timestamps, lengths and SHA-256 digests are retained in manifest.json.

Open Targets dedicates its Platform data under CC0 1.0. Its source licensing page lists underlying ChEMBL CC BY-SA 3.0, Reactome CC-BY 4.0 and Ensembl CC-BY 4.0 attribution. Preserve attribution and review source terms when reusing data outside Open Targets.

- [Open Targets licence](https://platform-docs.opentargets.org/licence)
- [Open Targets citation](https://platform-docs.opentargets.org/citation)
- [Open Targets clinical report definitions](https://platform-docs.opentargets.org/drug/clinical-report.md)
- [Ensembl terms](https://www.ensembl.org/info/about/legal/disclaimer.html)
- [ChEMBL](https://www.ebi.ac.uk/chembl/)
- [Reactome](https://reactome.org/)

AACT trial drug/disease labels include upstream LLM extraction in Open Targets. This repository preserves those source assignments; it does not independently validate clinical entity extraction. PharmaGenome's calculations use no LLM.

Report URLs retain their original HTTP or HTTPS scheme, including legacy FDA links. This snapshot is historical research evidence, not a current regulatory or treatment reference.
